## 🚀 **QUIC Probe Workflow (quic-probe.yml):**

### **Конфигурация:**
```yaml
name: QUIC Probe Tests

on:
  push:
    paths:
      - 'exporters/**'
  pull_request:
    paths:
      - 'exporters/**'

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v4
    
    - name: Setup Go
      uses: actions/setup-go@v5
      with:
        go-version: '1.25.3'  # Единственная версия
        cache: true
```

### **Тестирование:**
1. **Установка зависимостей** - `go mod download`
2. **Unit тесты** - `go test -v ./...`
3. **Race detection** - `go test -race -v ./...`
4. **Бенчмарки** - `go test -bench=. -benchmem ./...`
5. **Сборка** - `go build -o quic-probe .`
6. **Функциональный тест** - `./quic-probe --help`

### **Линтинг:**
1. **Staticcheck** - `staticcheck ./...`
2. **Go vet** - `go vet ./...`
3. **Форматирование** - `go fmt ./...`
